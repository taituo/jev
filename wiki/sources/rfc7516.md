# RFC 7516 — JSON Web Encryption (JWE)

RFC 7516 defines JWE for encrypting content with a JSON-based JOSE
header (RFC 7516 §1).

## Header parameters

- `alg` identifies the key-management algorithm; `enc` identifies the
  content-encryption algorithm (RFC 7516 §4.1.1, RFC 7516 §4.1.2).
- `zip` identifies an optional compression algorithm applied before
  encryption (RFC 7516 §4.1.3).
- Key hints such as `jku`, `jwk`, and `kid` parallel JWS usage
  (RFC 7516 §4.1.4, RFC 7516 §4.1.5, RFC 7516 §4.1.6).

## Producing and consuming

- Encryption and decryption procedures are defined separately
  (RFC 7516 §5.1, RFC 7516 §5.2).
- JWE and JWS objects are distinguishable by the rules in the
  distinguishing-objects section (RFC 7516 §9).

## Serializations

- JWE Compact Serialization is five base64url parts: protected header,
  encrypted key, initialization vector, ciphertext, authentication tag
  (RFC 7516 §7.1).
- Only one recipient is supported by the compact form; JSON
  serialization supports more structure (RFC 7516 §7.1, RFC 7516 §7.2).
