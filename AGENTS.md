# AGENTS.md — Audited Wiki Operating Policy

This is a Slice 1 audited LLM wiki. One human and one agent. Small diffs only.

## Boundaries

- `raw/sources/` is immutable. Never edit. Fetch only via `scripts/fetch_rfcs.py`.
- `wiki/` is generated/maintained. Every factual claim cites `RFC NNNN §X.Y`.
- `derived/sections.json` is generated by `scripts/split_sections.py`. Do not hand-edit.
- `fixtures/claims.jsonl` is frozen. Do not edit without a new commit and rationale.
- No network calls except the fetch script. No TypeSafe/Jev calls. No API keys.

## Citation rule

- Format: `RFC 7519 §4.1.4` (RFC number, section sign, section number).
- Every `RFC NNNN §X.Y` must exist in `derived/sections.json`.
- Prefer the most specific section (for example `RFC 7519 §4.1.4`, not `RFC 7519 §4`).
- Real conflicts cite both sides (for example `RFC 7519 §8` and `RFC 8725 §3.2`).

## Workflows

Ingest: confirm source ID → read source → check `wiki/index.md` →
propose pages → human review → write → update index + log → run tests.

Query: read index → read minimal pages → answer with citations →
file durable answers only when reusable.

Lint: run tests → report broken links, missing citations, orphans,
contradictions, stale claims. Fixes are a separate change.

## Trust

- Contradictions stay visible. Never silently merge.
- One ingest = one bounded diff. No concurrent writers in one checkout.
- Report what changed, what did not, checks run, open risks.
