# IETF Notice

This project references the following IETF RFCs as immutable sources:

- RFC 7519 — JSON Web Token (JWT)
- RFC 7515 — JSON Web Signature (JWS)
- RFC 7516 — JSON Web Encryption (JWE)
- RFC 6749 — The OAuth 2.0 Authorization Framework
- RFC 6750 — The OAuth 2.0 Authorization Framework: Bearer Token Usage
- RFC 8725 — JSON Web Token Best Current Practices

Source files are fetched verbatim from `https://www.rfc-editor.org`
and stored under `raw/sources/`. They are never edited by the wiki
maintainer; corrections arrive only as newly fetched revisions.

Copyright: the RFC texts are copyright the IETF Trust and the authors,
as stated inside each RFC. See `https://trustee.ietf.org/license-info`
for the IETF Trust Legal Provisions. This repository does not claim
ownership of the RFC texts and redistributes them unmodified for
reference and audit purposes only.

All wiki pages under `wiki/` are original summaries and syntheses.
Every factual claim there cites an RFC section (for example,
`RFC 7519 §4.1.4`) that can be mechanically resolved against
`derived/sections.json`.

The RFC texts in `raw/sources/` are not covered by the repository MIT license and remain under IETF Trust terms.
